# RationSahayak – AI-Powered Ration Assistance System

- Developed an AI-powered ration assistance platform using Python, FastAPI, Streamlit, and Groq, implementing Retrieval-Augmented Generation (RAG) with ChromaDB and FastEmbed to provide context-based answers with source citations.

- Implemented production-readiness features including LLM latency and token monitoring, a 10-minute response cache, 1,000-character input validation, and prompt-injection safeguards; achieved 19 passing automated tests using Pytest.

- Containerized and deployed the application using Docker and Render, established a GitHub Actions CI/CD pipeline, and evaluated two RAG configurations across 15 questions, achieving 100% retrieval accuracy and citation availability in the selected configuration.
